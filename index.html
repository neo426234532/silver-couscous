BPB Route Cleaner

Remove China-specific GeoIP / GeoSite routing from BPB/Xray configurations.

Removed

  • geoip:cn routing rules
  • geosite:cn routing rules
  • DNS rules using expectIPs: ["geoip:cn"]
  • China-specific domestic DNS tags
  • Routing rules referring to removed China DNS tags

Preserved

  • VLESS server and UUID
  • TLS and WebSocket configuration
  • TLS fingerprint and cipher suites
  • Fragment / finalmask settings
  • Normal DNS configuration
  • Private IP and private domain direct routing
  • Google proxy routing
  • Other non-China routing rules
